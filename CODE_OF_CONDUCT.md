# Code of Conduct

AXIS-Library is a commons. Everyone who participates — contributors,
maintainers, consumers, agents, and the humans operating them — is expected to
help keep it a place that stays useful and accountable.

## Expected behavior

- Be honest about what your contribution does. Contracts and effect
  declarations are claims; treat them as commitments, not suggestions.
- Disclose AI assistance materially. If a model generated or transformed code
  you submitted, say so in the PR.
- Take responsibility for what you publish. If your function turns out to be
  wrong or insecure, file a revocation promptly through the runbook.
- Review others' submissions in good faith. Reviews are about whether the
  contribution meets the bar, not about the contributor.
- Disagree on substance, not on people. Discussions about whether a function's
  contract is sufficient or its design is sound are welcome. Personal attacks
  are not.

## Unacceptable behavior

- Knowingly submitting code that violates licenses, infringes patents, or
  copies proprietary work.
- Misrepresenting the verification status, contracts, or provenance of a
  submission.
- Using the trust system to vouch for code you haven't actually reviewed.
- Harassment, discrimination, or personal attacks against contributors,
  maintainers, or operators of agents.
- Submitting code intended to harm consumers (malicious payloads, exfiltration,
  denial of service against the registry).

## Enforcement

Maintainers may:

- Request changes to PRs that don't meet the bar.
- Reject submissions that violate this code or the contribution terms.
- Revoke trusted publisher status for repeated or serious violations.
- Issue signed revocation feeds for entries that turn out to be harmful.
- Restrict participation from contributors who repeatedly act in bad faith.

## Reporting

Issues with submissions, conduct, or process should be raised through GitHub
issues using the appropriate template. Sensitive reports (security
vulnerabilities, key compromise, harassment) should go to the maintainer
incident contact listed in the relevant publisher record or in the repository's
SECURITY.md when available.

## Scope

This code applies in all AXIS-Library spaces — issues, pull requests, code
review comments, governance discussions, and any associated forums. It also
applies to interactions between AI agents and human operators when those
interactions touch the library.
